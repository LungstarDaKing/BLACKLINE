# characters/civilians

**What belongs here:** background pedestrians and bystanders for Cape Town streets. Authentic, varied and respectful: avoid stereotypes.

**Format:** GLB preferred. **Skeleton:** REQUIRED (shared humanoid) so they can reuse Idle/Walk clips. **Animations:** Idle, Walk (in place).
**Budget:** these appear in numbers, so keep them cheap: about 3,000 to 6,000 triangles, one 512 px texture atlas per variant, no per-character unique shaders.
**Orientation and scale:** faces -Z, feet at Y = 0, 1 unit = 1 m, 1.5 to 1.9 m tall.
**Record keeping:** source, author, licence, date in `docs/ASSET_LICENSES.md`; status in `docs/ASSET_CATALOGUE.md`.
