# characters/antagonists

**What belongs here:** named story antagonists and lieutenants (not generic guards: see `security/`). Names are not final canon.

**Format:** GLB preferred (FBX accepted).
**Skeleton:** REQUIRED. Rigged humanoid. Use the SAME skeleton/bone naming as the protagonist wherever possible so one animation set drives every character.
**Animations:** Idle, Walk, Run, Jump, Fall, plus combat clips later (aim, fire, hit reaction, death). In-place locomotion.
**Orientation and scale:** faces -Z, feet at Y = 0, 1 unit = 1 m, about 1.7 to 1.9 m tall. Budget about 8,000 to 12,000 triangles, textures 512 to 1024.
**Textures:** embedded in the GLB, or in a `textures/` sub-folder beside the model.
**Record keeping:** source, author, licence, date in `docs/ASSET_LICENSES.md`; status in `docs/ASSET_CATALOGUE.md`.
