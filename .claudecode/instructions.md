# Godot 4.7 Project Rules
- Language: GDScript 2.0 (Godot 4.x syntax).
- Typing: Use static typing wherever possible (e.g., `var score: int = 0`).
- Onready: Use the `@onready` annotation instead of the old `onready var` syntax.
- Signals: Use the new signal syntax (e.g., `button.pressed.connect(_on_button_pressed)`).
- Formatting: If `gdformat` is available on the Windows system, use it to format modified scripts.
